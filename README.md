Activity Description

This activity focuses on implementing and understanding two fundamental data structures: Stack and Queue. It involves using HTML, CSS, Bootstrap, JavaScript, and jQuery to create interactive simulators.

The Stack Simulator demonstrates the LIFO (Last In, First Out) principle through Push, Pop, Peek, and Clear operations.

The Queue Simulator demonstrates the FIFO (First In, First Out) principle through Enqueue, Dequeue, Peek, and Clear operations.

Both simulators include interactive features to demonstrate how these data structures work.
